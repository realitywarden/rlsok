Prepare a check workspace for your robot

Choose your project folder in the local assistant. It shows recognized descriptions and configuration files, what is missing, and the next step. No account, AI service or robot command is needed.

1. Extract the ZIP

In File Explorer, right-click the downloaded ZIP and choose Extract All. Open the extracted folder.

2. Double-click “Start setup assistant.cmd”

Open your own project folder in the local browser workflow. The assistant can import a saved interface catalog without Python. Live ROS discovery needs Python and the documented sourced ROS environment. It cannot infer field units, physical meaning or the active robot from file structure; confirm these before exporting a check workspace. Files stay on this computer.

Other local checks remain available

Run example.cmd opens an optional example result page. Keep your original files. The included guides also cover:

  • Compare saved robot settings with a reviewed copy
  • Choose which settings and source files to check
  • Discover interfaces and compose reusable template fragments

Or open Terminal in this extracted folder and run:

.\bin\rlsok.cmd setup-assistant

Existing profile, saved-file and observer commands remain unchanged.

Your computer stays yours

This download checks local files and supplied observations; it does not send robot commands. It does not replace the separate RLSOK management app or a robot's running software.

To remove the tool, delete its extracted folder. Reports stay in %LOCALAPPDATA%\RLSOK\Local Check\Reports; delete that folder only if you no longer want those reports.

Need help? Send the version and error text to support@rlsok.com. Review files before sharing; they can contain project details.
