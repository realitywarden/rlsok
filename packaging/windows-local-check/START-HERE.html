RLSOK LOCAL CHECK 1.5.10 · WINDOWS 10 / 11 · INTEL / AMD 64-BIT

See what changed in your robot settings

Start with an example on your own computer. No account, robot, database, Python or separate Node.js installation is needed for the example.

1. Extract the ZIP

In File Explorer, right-click the downloaded ZIP and choose Extract All. Open the extracted folder.

2. Double-click “Run example.cmd”

Your browser will open a local result page showing matching settings and a changed calibration. Nothing is uploaded. If it does not open automatically, the command window prints the result file location.

Ready to use your own files?

Keep your original files. Choose the included guide that matches what you want to compare:

  • Compare saved robot settings with a reviewed copy
  • Choose which settings and source files to check
  • Discover interfaces and compose reusable template fragments

The command entry point on Windows is .\bin\rlsok.cmd. Open Terminal in this extracted folder and start with:

.\bin\rlsok.cmd profile help
.\bin\rlsok.cmd profile compose-templates --input base.template.json --input controller.template.json --output composed.template.json

Where a guide uses ./bin/rlsok, use .\bin\rlsok.cmd. Template composition and saved-file checks are local. Some optional source-file helpers need Python; ROS graph capture needs its documented ROS environment.

Your computer stays yours

This download checks local files and supplied observations; it does not send robot commands. It does not replace the separate RLSOK management app or a robot's running software.

To remove the tool, delete its extracted folder. Reports stay in %LOCALAPPDATA%\RLSOK\Local Check\Reports; delete that folder only if you no longer want those reports.
