# RLSOK Local Check 1.5.5

This release gives the local file-checking workflow a clear current version on
Linux, Windows and macOS. The Mac package adds a real native local console
instead of presenting an AppleScript choice dialog as the application surface.

## Platform delivery

- macOS 14 or later receives separate native Apple-silicon and Intel builds.
  The SwiftUI console uses the same dark, dense hierarchy as the Windows local
  console and Cloud Workspace while exposing only capabilities that exist in
  the Mac Local Check package.
- The console shows package identity, local-only and zero-dispatch boundaries,
  runs the included example, retains an audit log and opens the resulting local
  reports and bundled guide.
- Windows and Linux carry the same 1.5.5 Local Check payload and example result
  meanings. Historical packages and URLs remain unchanged.

## Verification and limits

The platform releases are recorded separately. Linux source/distribution
verification does not prove a Mac app. Each Mac installer must be compiled,
installed and checked on its matching standard GitHub-hosted architecture; the
installed app executable must pass its resource self-check and the bundled CLI
must still produce `WOULD_ALLOW` and `WOULD_BLOCK` example reports before that
Mac release is published.

The Mac packages are not Developer ID signed or notarized. The console compares
saved inputs and launches the included zero-command example. It does not connect
to a robot, infer which configuration a controller loaded, dispatch motion,
replace independent safety, or establish customer use or acceptance.
