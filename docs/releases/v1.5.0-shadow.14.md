# v1.5.0-shadow.14 — Pioneer-X saved tracker comparison

Adds an independent `pioneer-x` preparation recipe for saved Pure Pursuit and
MPC settings and the selected ESP32 firmware source. It includes the master,
navigation, tracker and teleop source with build declarations and a source-path
map. A selection helper and explicitly labeled source-default examples are
included. See [the complete workflow](../pioneer-saved-review.md).

The reviewed public source is
[39f67a06](https://github.com/DaneelOlivawXJose/pioneer-ros2-diff-drive/tree/39f67a0697f8b28669c26edfe5ca2124348756d7).
The report shows actual before/after fields, including lookahead 0.6 → 0.7 and
an algorithm switch, while keeping the original baseline. Missing selections,
unknown algorithms/fields and invalid settings are refused during preparation;
later unreadable copied files remain visible as missing material.

CARROT/PROPORTIONAL requires the actual updated node/remapping: the reviewed
master's route topic differs from the proportional node's subscription, and
that node has no settings callback. No working integration of that path is
claimed. Current SCADA settings are not in the public checkout.

## Verification and boundary

- TypeScript build completed.
- Twelve focused offline checks: unchanged Pure Pursuit/MPC, lookahead,
  velocity, firmware and master source changes, malformed copied JSON,
  algorithm switching, missing field, reversed angular bounds, fractional
  interpolation count and unsupported algorithm. The helper/CLI preparation
  also completed with 23 selected files.
- No full test suite, GitHub Actions, ROS, SCADA, micro-ROS, node launch,
  firmware execution, WiFi connection or motor command.
- This is a saved-file comparison, not live switch interception, command
  arbitration, flashed-firmware verification, Humble compatibility or a
  tracking-performance result. Customer settings, use and acceptance remain
  separate.

Includes the previously published shadow.13 ArmPilot and Beast improvements.
Stable Runtime stays v1.4.5; the Windows desktop update channel is unchanged.
