# v1.5.0-shadow.13 — independent ArmPilot review and Beast node parameters

This evaluation prerelease adds two independent ArmPilot saved-file recipes
and fixes preparation/inspection of Dons Beast's new per-node parameter YAML.
Stable Runtime remains v1.4.5; this does not change the Windows desktop channel.

## ArmPilot saved configuration prototype

`armpilot-remote` captures the selected serial/ACK, joystick mapping, direction
and deadband configuration with host and firmware source. `armpilot-3d`
captures the selected MeArm-V1 backend, selector, package/model/calibration,
physics and URDF with the related source. A standard-library selection helper
reduces manual file entry. Source IDs are mapped to repository paths in the
saved manifest, which supports up to 200 files for the complete selected set.

The prototype is separate from the upstream framework and command path.
It reads [zc110747/MeArmPilot b142fe94](https://github.com/zc110747/MeArmPilot/tree/b142fe9427399b581d820d24c9d7643a69931ea5)
without importing or running it. See [the walkthrough](../armpilot-saved-review.md).
Installed firmware, EEPROM and live overrides are not discovered. Source or
configuration equality does not authorize motion or establish physical position.

## Beast parameter selection

[Dons_Beast f16b4e4a](https://github.com/Dwilliestyle/Dons_Beast/commit/f16b4e4a0010570fd47e2843ac4ade635e17b997)
removes the duplicate voltage key, selects `cmd_vel_timeout` and separates
parameters by node. The inspector/preparer now handle `esp32_bridge`,
`/esp32_bridge` and earlier `/**` blocks. Teleop speed and odometry geometry
remain attached to their own saved nodes. Conflicting selectors are refused;
identical serial bindings are all updated during explicit resolution. This
does not evaluate launch overrides or read live parameter values.

## Delivery verification

- TypeScript build completed.
- 20 focused offline cases completed using the pinned public sources and
  synthetic changed copies: unchanged baselines, baud/deadband/role/source,
  mode/ACK/settle/calibration/limit/package changes, invalid YAML, Beast's new
  node file, timeout/speed/geometry changes, conflicting selectors and explicit
  resolution of overlapping serial fields.
- Both selection-helper/CLI preparation paths completed; the 3D check also
  read the selected serial-mode YAML without launching it.
- No full test suite or GitHub Actions; no ROS, ArmPilot frontend/backend,
  simulator, driver, firmware, serial/CAN/UDP/WebSocket/TCP connection or robot
  motion. No customer hardware validation, use or acceptance is claimed.

The first offline run exposed an 80-file manifest limit. The 99-file 3D snapshot
now fits within a 200-file bound and the final 20-case run completed. These are
delivery checks for the stated file workflow, not evidence of every possible
configuration or an absolutely defect-free release.
