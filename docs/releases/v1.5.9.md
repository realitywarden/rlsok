# RLSOK Local Check 1.5.9

This release adds reusable self-service connection templates without adding an
AI service or making local customer configuration available to RLSOK.

## Versioned local templates

- `RlsokConnectionTemplate` separates reusable interface types, adapter field
  mappings and fact descriptors from device identity, real goals, source files
  and expected values.
- `rlsok profile inspect-template --input template.json --catalog catalog.json`
  matches a template against fresh read-only discovery and reports matched,
  missing or ambiguous paths. It generates no goals, observations, approvals or
  robot commands.
- Exact interface fingerprints and endpoint hints can remain in a private
  template. Applying any template still requires real local values and explicit
  confirmation of meanings, units, frames and limits.
- The generated JSON Schema is included with the other local contracts.

## Local privacy and optional contribution boundary

The web configuration flow can explicitly save a complete setup in that
browser's IndexedDB or export it as a private file. Nothing is saved
automatically and file bytes are not placed in browser storage.

A separate contribution-candidate export removes endpoint names, ROS
distribution, fingerprints, robot/controller defaults, joint order, goals,
device identity, expected values, frame values, limits and allowlist entries.
Interface names, field mappings and JSON pointers remain visible for review.
Creating this file neither uploads it nor grants RLSOK rights; submission needs
a separate agreement and review before it can enter an official template
library.

## Verification and limits

TypeScript type checking completed for the Runtime and web source. The release
package build records its exact source and generated assets. No full test suite,
GitHub Actions, ROS graph, installer execution or physical robot check was run.
The new template planner validates configuration structure and discovery
matching only. It does not infer proprietary semantics, prove compatibility,
authorize motion or establish customer use or acceptance.
