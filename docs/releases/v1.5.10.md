# RLSOK Local Check 1.5.10

Released 22 September 2026.

## What changed

- Compose one to sixteen versioned `RlsokConnectionTemplate` fragments in a
  deterministic order with `rlsok profile compose-templates`.
- Paths and fact descriptors combine. Later fragments override earlier robot
  defaults; conflicting ROS distributions and contract limits fail closed.
- The same command and contract are included in the Windows, macOS and Linux
  local packages. The cloud-hosted wizard performs the same composition in the
  browser and does not upload fragment contents.
- Windows start instructions and the native macOS console now point directly
  to the interface setup workflow.

## Verification scope

TypeScript type checking, build and focused command review were completed.
Packaging, native installation/execution and publication are recorded
separately; a built artifact is not represented as installed or accepted.

No physical robot, private customer interface or customer acceptance was
tested. Template composition does not infer semantics, authorize motion or
establish that a configuration is active on a controller.
