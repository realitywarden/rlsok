# RLSOK Local Check 1.5.3

This numbered release turns recent operator feedback into reviewable,
zero-command checks. It does not claim that any recipient installed the tool,
connected a robot, ran a trial or accepted the result.

## Changes

- Three source-workspace mappings for a six-wheel UDP rover, MIRA's guarded
  PX4 offboard velocity input and one ordered fourteen-joint dual-LBR action.
- Saved setup recipes for RobStride ROS-coordinate command envelopes, Dobot
  Magician homing inputs without calling the motion service, and direct
  LeRobot SO-101 leader/follower serial workflows.
- A navigation preflight report covering selected DDS peers, clock skew,
  lidar configuration/rate/freshness, TF, scan/odometry consistency and Nav2
  lifecycle readiness. It reports `WOULD_ALLOW` or `WOULD_BLOCK` and publishes
  no goal or velocity command.
- A proof-gated device-handshake attestation. Configured IDs, USB paths and
  CAN/RS485 addresses do not create authenticated identity capabilities.
- An EtherCAT + ros2_control selection contract and guide for encoder offsets,
  slave/PDO/DC configuration, controller ownership and source/build identity.
- A source-to-binary map for the collector, comparison/evidence logic, CLI and
  platform packaging entry points.

## Verification and limits

Focused local checks passed for the three new saved recipes, navigation
preflight allow/block cases, source-workspace refresh/mismatch behavior, the
adapter reference contracts, all existing composable-profile cases and the
TypeScript production build. Source paths were also checked against the named
public upstream revisions for LeRobot, RobStride and Dobot.

No full local test suite, physical robot, serial/CAN/EtherCAT connection,
controller activation, homing operation, Nav2 command or flight command was
run for this feedback work. A matching saved review is not proof of the active
machine, installed binary, mechanical correctness, safety, actual use or
customer acceptance. Live capabilities require a fresh integration-owned
observer and the exact external gates documented for each contract.

Windows Local Check and Mac local-workspace downloads are separate platform
packages. Their pages and embedded versions must be read independently; this
runtime release does not silently change either feed. Historical releases,
checksums, guides and previously emailed links remain available.
