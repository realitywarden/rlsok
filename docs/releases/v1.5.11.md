# RLSOK Local Check 1.5.11

Released 22 September 2026.

## What changed

- Added `rlsok setup-assistant`, a shared local browser workflow for Windows,
  macOS and Linux.
- The assistant can run the existing read-only ROS discovery, import a saved
  catalog, combine up to sixteen versioned template fragments, match their
  interfaces and export one local setup workspace.
- It binds only to `127.0.0.1`, uses a random per-session URL, loads no external
  page resources and exposes no cloud upload or robot-command endpoint.
- Existing profile commands, adapters, saved-file recipes, observers, schemas
  and previous versioned downloads are unchanged. The assistant calls the same
  validated catalog, template-composition and matching contracts.

## Important limits

Automatic matching does not infer custom meaning, units, frames or physical
identity. Users still confirm those semantics and supply real examples and
selected files before local evaluation. Live discovery requires a sourced ROS
2 environment; catalog import and template composition do not.

This implementation and publication do not establish compatibility with a
private customer interface, use on a physical robot, repeat use or customer
acceptance. It sends no controller command and grants no motion permission.

## Focused verification

TypeScript type checking and build completed. The local HTTP surface was
started on Windows and checked for loopback binding, per-session access,
security headers, adapter listing, bounded template composition and workspace
generation. The full test suite was not run.
