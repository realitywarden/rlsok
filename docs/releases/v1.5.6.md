# RLSOK Local Check 1.5.6

This release moves the reusable fixes learned from the latest customer trials
into the public Local Check package instead of leaving them only in one-off
downloads.

## Included fixes

- Source-bound observers now record the actual checkout commit, dirty state and
  origin instead of trusting a separately typed version.
- ROS 2 graph inspection can preserve valid Fast DDS endpoints whose node name
  is unavailable and bind a unique command/observation pair by its DDS
  participant GID. It still fails closed on ambiguity or mismatched participants.
- The public CLI exposes the read-only MIRA, TRIK, LelyRobot, reBot, dual-Kinova,
  warehouse-Gazebo, Ruiyan-hand and PiDog capture paths shipped in the package.
- The Workbench offline Shadow path now attaches a measured fail-closed adapter
  to the actual customer execution-controller boundary. The public CLI passes
  both distinct drafts and the exact source checkout required by that evaluator.
- Observer output creation remains fail-closed: existing output files are never
  overwritten and robot-facing capture commands require their explicit inputs.

## Scope and limits

Windows, macOS and Linux packages carry the same 1.5.6 Local Check source
payload. The included customer-derived profiles remain opt-in and do not claim
universal compatibility. Most observers subscribe to existing state only;
Ruiyan RS485 performs only the documented read requests after an explicit
read-only confirmation. No package sends motion commands or replaces independent
safety controls.

This release records packaging and focused source review, not a full local test
suite or a physical-robot acceptance result. Customer-run hardware results are
still required before claiming that a specific robot integration is accepted.
