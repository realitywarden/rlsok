# RLSOK Local Check 1.5.0

This is the numbered release of the local file and example-input checking
tool. It includes the functionality previously published through
1.5.0-shadow.14, with a plain-language first-run guide and corrected packaging.
It is not an upgrade of the robot execution runtime or Windows management app.

## What changed

- Start with an included example on Ubuntu, without a robot, ROS or account.
  The guide explains the two results and then links to the relevant own-file workflow.
- The package, launcher version, installation scripts and current first-run
  instructions use 1.5.0. Package generation renders the installer from the
  package version and refuses missing or unresolved template fields.
- Corrects an actual delivery defect: install-shadow.sh attached to shadow.13
  and shadow.14 selected shadow.12. Those historical assets are retained with
  their original checksums. New installations should use this release's
  installer or the directly pinned archive commands.
- Retains ArmPilot, Beast, Pioneer-X Pure Pursuit/MPC and prior local checks.
  Pioneer Carrot remains unsupported. No customer-specific integration or
  hardware acceptance is added by changing the release designation.
- The website directs first-time users by purpose and computer, keeps exact
  version details available, and preserves old download-page fragments.

## Version and compatibility

Future compatible fixes increment the final version number; compatible
feature additions increment the middle number. Preview suffixes are reserved
for actual preview releases. Shadow still describes a read-only workflow,
not the required naming of every release.

No profile or evidence schema changes, automatic upgrades, credential
changes, cloud/database migrations or robot commands are introduced. Install
in a new directory; existing approved baselines remain explicit and unchanged.
Robot-runtime 1.4.5 and Windows feeds keep their actual versions and artifacts.
This scoped local-tool release does not replace the robot-runtime latest feed.

## Verification scope

Delivery uses the TypeScript build and manual package assembly, source/diff
review, inspection of generated installer version/archive bindings, package
checksums, and a focused run of the packaged sample using the host Node runtime.
The previous 32 targeted ArmPilot/Beast/Pioneer offline checks remain recorded
under their original releases; they are not represented as newly rerun tests.
No full local test suite or GitHub Actions is run. The Linux installer and
Linux executable are not executed on this Windows build host. Installation
on a customer's computer, private interfaces, live robot state and physical
operation remain outside the evidence. See BUILD-MANIFEST.json and the
published guides for each workflow's requirements and limits.
